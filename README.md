# 🎓 НМО Автоответчик (Firefox Extension)

Расширение для автоматического ответа на тесты НМО на платформе QuizLib / НМИФО (iom-spo.edu.rosminzdrav.ru) с использованием базы ответов с **rosmedicinfo.ru**.

## ✨ Возможности

- 🔍 **Фоновый поиск** теста по названию на РосМедИнфо (не переключает фокус)
- 💾 **Автосохранение** ответов при открытии страницы с ответами
- 🤖 **Полуавтоматический режим:**
  - **Радиокнопки** — выбирает автоматически
  - **Чекбоксы** — подсвечивает зелёной рамкой + ✅, пользователь кликает сам
- ➡️ **Автопереход** на следующий вопрос после клика чекбоксов
- ⏹ Остановка в любой момент

## 📋 Установка

1. Откройте Firefox
2. Перейдите на `about:debugging`
3. Нажмите **"This Firefox"** → **"Load Temporary Add-on"**
4. Выберите файл `manifest.json` из папки `nmo-solver`

## 🚀 Использование

### 1. Подготовка ответов
1. Откройте страницу с ответами на РосМедИнфо:
   ```
   https://rosmedicinfo.ru/studenti/answers-to-nmo-tests/...
   ```
2. Расширение **автоматически** распознает вопросы и правильные ответы (по жёлтому фону `fbeeb8`)
3. Появится уведомление: `✅ Сохранено N вопросов!`

> ⚠️ **Важно:** На РосМедИнфо есть тесты **без разметки** правильных ответов (только текст). Парсер их не прочитает — увидишь `❌ Не удалось найти ответы`.

### 2. Прохождение теста
1. Откройте страницу теста (QuizLib / НМИФО)
2. В правом нижнем углу появятся кнопки:
   - `🔍 РосМедИнфо` — найти ответы для текущего теста в фоне
   - `🤖 Авто` — запустить полуавтоматический цикл
3. Нажмите `🤖 Авто`
4. **Радиокнопки** выберутся сами
5. **Чекбоксы** подсветятся зелёной рамкой с пульсирующим ✅ — кликните их вручную
6. После отметки всех подсвеченных чекбоксов — скрипт **сам нажмёт "Следующий вопрос"**
7. Повторяется до конца теста → `🏁 Тест завершён!`

## 🔧 Как это работает

### Страница с ответами (`answers_page.js`)
- Парсит вопросы в `<h3>` внутри `.page__text`
- Извлекает варианты из следующего `<p>`/`<div>` через `<br>`
- Определяет правильные ответы по стилю `background-color:#fbeeb8` (жёлтый фон)
- Сохраняет в `browser.storage.local` под ключом `nmoAnswers`

### Страница теста (`test_page.js`)
- Находит текущий вопрос по селектору `.question`
- Извлекает текст вопроса (`.question-title-text`) и варианты (`mat-radio-button`, `mat-checkbox`)
- Нечёткое совпадение (Levenshtein, порог 75%) с сохранёнными ответами
- **Радио**: `input.checked=true` + `dispatchEvent('change')`
- **Чекбоксы**: только визуальная подсветка (`border: 2px solid #4CAF50` + `✅`)
- Ждёт отметки всех подсвеченных чекбоксов → кликает кнопку "Следующий вопрос"

## 🐛 Отладка

```javascript
// В консоли страницы теста (F12):
browser.storage.local.get('nmoAnswers').then(r => console.log(r.nmoAnswers));

// Проверить текущий вопрос:
document.querySelector('.question-title-text')?.textContent;
document.querySelectorAll('mat-radio-button, mat-checkbox').length;
```

## ⚠️ Известные ограничения

1. **Не все тесты на РосМедИнфо имеют разметку** — если нет жёлтого фона, парсер не найдёт ответы
2. **Только Firefox** (Manifest V2, `browser.*` API)
3. Селекторы под конкретную вёрстку QuizLib — при изменении UI нужно обновлять `test_page.js`
